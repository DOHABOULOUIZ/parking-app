========================================

✅ Draw.io est déjà ouvert dans votre navigateur !

ÉTAPES À SUIVRE (5 minutes) :

1️⃣  Dans Draw.io :
   - Cliquez sur "File" → "Open from" → "Device"
   - Sélectionnez : MCD_PARKING_TEMPLATE.drawio
   - Votre MCD s'affiche automatiquement ! 🎉

2️⃣  Vérifiez le MCD :
   - Toutes les entités sont là : SECTEUR, PLACE, RÉSERVATION, UTILISATEUR, PAIEMENT
   - Toutes les associations (losanges) sont présentes
   - Ajustez si nécessaire (couleurs, textes, positions)

3️⃣  Exportez en PNG haute qualité :
   - File → Export as → PNG
   - IMPORTANT : 
     * Zoom : 300% (pour haute résolution)
     * Transparent Background : ✓ COCHER
     * Border Width : 10
   - Cliquez "Export"

4️⃣  Sauvegardez le fichier :
   - Nom : MCD_Parking.png
   - Emplacement : CE MÊME DOSSIER (à côté du rapport HTML)

5️⃣  Actualisez le rapport :
   - Retournez dans votre navigateur (rapport ouvert)
   - Appuyez sur F5 (actualiser)
   - Le MCD s'affiche ! ✅
