🎯 ÉTATS INTERACTIFS IMPLÉMENTÉS
═══════════════════════════════════════════════════════════════════════════════

1️⃣ HOVER - Survolage
   ├─ Boutons: Remontée (-2px) + ombre aggrandie
   ├─ Cartes: Bordure bleue + translateY(-4px)
   ├─ Inputs: Bordure foncée + bg léger
   ├─ Badges: Scale 1.05 + ombre
   ├─ Navigation: Bg bleu clair + indent
   └─ Tables: Bg gris clair + outline bleu

2️⃣ ACTIVE - Clic/Pression
   ├─ Boutons: Enfoncement (translateY 0) + ripple effect blanc
   ├─ Cartes: Transform réduit
   ├─ Inputs: Focus avec border bleue
   ├─ Badges: Scale 0.98 (feedback tactile)
   ├─ Tables: Bg bleu clair intensifié
   └─ Navigation: Style persistant (actif)

3️⃣ FOCUS - Clavier (Tab)
   ├─ Inputs: Outline bleu + offset 2px
   ├─ Boutons: Outline visible pour a11y
   ├─ Liens: Outline + border radius
   ├─ Checkboxes: Outline + scale 1.1
   └─ Modals: Trap focus avec Tab

4️⃣ DISABLED - État désactivé
   ├─ Opacité 0.6 sur tous les éléments
   ├─ Curseur: not-allowed
   ├─ Pas d'effets hover
   ├─ Désactivé au clavier
   └─ Accessible aux lecteurs d'écran

5️⃣ VALIDATION - États d'error/success
   ├─ Input.success: Bordure verte + halo vert 0.1
   ├─ Input.error: Bordure rouge + halo rouge 0.1
   ├─ Transition smooth entre états
   ├─ Visual feedback immédiat
   └─ Compatible validation temps réel

6️⃣ FOCUS-VISIBLE - Clavier uniquement
   ├─ Pas de outline au mouse/touch
   ├─ Outline visible au clavier (Tab)
   ├─ Améliore l'accessibilité
   ├─ Suit les standards WCAG
   └─ Utilise :focus-visible

7️⃣ SÉLECTION - États de sélection
   ├─ Table rows: Classe .selected
   ├─ Navigation: aria-current="page"
   ├─ Badges: Classe .active
   ├─ Cartes: Classe .selected
   ├─ Visual feedback persistant
   └─ Support au clavier

8️⃣ ANIMATIONS - Transitions 60fps
   ├─ transitions: 150-350ms smooth
   ├─ Cubic-bezier optimisés
   ├─ Hardware accelerated (transform)
   ├─ Prefix-free moderne
   ├─ Respect prefers-reduced-motion
   └─ Performance garantie Lighthouse


🎨 TIMING FUNCTIONS UTILISÉES

🚀 UTILISATION IMMÉDIATE
═══════════════════════════════════════════════════════════════════════════════

1️⃣ Les états interactifs sont appliqués AUTOMATIQUEMENT:

   <button>Cliquez-moi</button>
   → Hover, active, focus, disabled tous fonctionnels!

   <input type="text" />
   → Focus bleu, validation rouge/verte, tous automatiques!

   <a href="/page">Lien</a>
   → Hover, visited, focus-visible tous fonctionnels!

2️⃣ Pour ajouter des validations:

   <input 
     type="email"
     className={isValid ? 'success' : 'error'}
   />

3️⃣ Pour rendre les éléments interactifs:

   <table>
     <tr 
       className={selected ? 'selected' : ''}
       onClick={() => setSelected(!selected)}
     >

4️⃣ Pour la navigation active:

   <a 
     href="/page"
     aria-current={currentPage === 'page' ? 'page' : undefined}
   />
