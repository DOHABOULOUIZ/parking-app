## ❓ Problèmes Courants

### "Le fichier HTML ne s'ouvre pas dans Word"
**Solution :**  
- Ouvrez d'abord Word
- Fichier → Ouvrir → Sélectionnez le HTML
- Changez le filtre pour "Tous les fichiers (*.*)"

### "Les couleurs sont différentes"
**Solution :**  
C'est normal ! Word convertit les couleurs CSS en couleurs Word.  
Vous pouvez les ajuster manuellement si nécessaire.

### "Le MCD est flou"
**Solution :**  
Le diagramme SVG peut perdre en qualité. Options :
1. Augmenter le zoom Word à 150%
2. Demandez-moi de créer un nouveau MCD en haute définition
3. Utilisez l'Outil Capture pour faire un screenshot net
